# small_calc_proj

Small multi-language calculation examples for applied physics and engineering.

Current examples are implemented in:

- Python
- Julia
- C++

Each demo includes small calculations relevant to RF/signal processing/ML:

- Free-space path loss (RF)
- RMS of a sampled signal (signal processing)
- Linear model prediction (ML/math)

## Run

### Python

```bash
python3 python/calc_demo.py
```

### Julia

```bash
julia julia/calc_demo.jl
```

### C++

```bash
g++ -std=c++17 cpp/calc_demo.cpp -o /tmp/calc_demo
/tmp/calc_demo
```
